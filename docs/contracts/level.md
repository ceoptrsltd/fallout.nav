# Контракт: уровень (крен и тангаж по MPU-6050) — калибровка в админке, виджет на экране

Датчик — тот же MPU-6050, что у охраны (docs/contracts/alarm.md §1–2): один поток чтения на оба потребителя.
Тексты интерфейса и ответов API — на английском.

## Оси и знаки

Система машины: **F** — вперёд, **R** — вправо, **U** — вверх. Акселерометр в покое показывает вектор «вверх»
(≈ +1 g). `a` — сглаженный (EMA τ = 1 с) вектор акселерометра в осях датчика, переведённый в оси машины матрицей
калибровки: `aF = a·F`, `aR = a·R`, `aU = a·U`.

- `pitch_deg = atan2(aF, hypot(aR, aU))` — **продольный**: > 0 — перед выше зада.
- `roll_deg = atan2(aR, hypot(aF, aU))` — **поперечный**: > 0 — правый борт выше левого.

Округление для показа — 0,1°. «Ровно» — оба угла по модулю ≤ 0,3°.

## Калибровка (хранится в `settings.level.calibration`)

`LevelCalibration = {up: [x, y, z], forward: [x, y, z], method: "single"|"two_point", forward_source: "axis"|"driving",
axis: "x+"|"x-"|"y+"|"y-"|"z+"|"z-"|null, ts: float}` — векторы в осях датчика, нормированы.
Базис машины: `U = up`, `F = normalize(forward − (forward·U)·U)`, `R = F × U`.

1. **Ноль (`up`)** — замер: среднее за 3 с, только если машина неподвижна (разброс |a| ≤ 0,01 g и угол ≤ 0,3° за
   замер; иначе 409 «The van is moving or rocking. Keep still and try again»).
   - `single` — машина стоит на ровном месте: `up = normalize(a)`.
   - `two_point` — точно, не нужно ровное место: замер 1, развернуть машину на 180° на том же месте, замер 2;
     `up = normalize(a1 + a2)` (уклон площадки вычитается).
2. **Вперёд (`forward`)**:
   - `axis` — какая ось датчика смотрит вперёд (по стрелкам X/Y на плате), по умолчанию `x+`;
   - `driving` — по ходу: во время разгонов/торможений по GPS (|dv/dt| ≥ 0,8 м/с², скорость ≥ 5 км/ч, курс почти
     не меняется) копится сумма `h · dv/dt`, где `h` — горизонтальная (⊥ U) часть ускорения минус тяжесть;
     набралось ≥ 5 с таких участков и направление устойчиво (разброс ≤ 10°) — `forward = normalize(сумма)`,
     калибровка сохраняется, обучение заканчивается само.
3. Без калибровки: `up` — ось датчика, ближайшая к текущей тяжести; `forward` — `x+`; `calibrated: false`.

## Настройки `settings.level` (`LevelSettings`)

| Поле | По умолчанию | Пределы | Смысл |
|---|---|---|---|
| `show_on_screen` | true | | показывать виджет на экране, когда машина стоит |
| `wheelbase_m` | 3.5 | 1.5–7.0 | колёсная база, м |
| `track_m` | 1.7 | 1.0–3.0 | колея, м |
| `calibration` | null | | см. выше |

## Подкладки под колёса

Высота точки колеса над «ровной» плоскостью: `h = x·tan(pitch) + y·tan(roll)`, где `x = ±wheelbase/2`
(перед +), `y = ±track/2` (правый +). Подложить под колесо: `raise = max(h) − h` (см, шаг 0,5). Самое высокое
колесо — 0.

## API (с сессией)

`LevelStatus = {sensor_ok: bool, calibrated: bool, pitch_deg: float|null, roll_deg: float|null, still: bool,
raw: [x, y, z]|null (g, оси датчика, сглаженный), wheels_cm: {fl, fr, rl, rr}|null, calibration: LevelCalibration|null,
wizard: {two_point_step: 0|1 (1 — первый замер сделан, ждём второй), learning: bool, learn_s: float (набрано секунд),
learn_spread_deg: float|null}}`

| Метод | Путь | Тело → ответ |
|---|---|---|
| GET | `/api/level` | `LevelStatus` |
| POST | `/api/level/calibration/level` | `{"method": "single"}` или `{"method": "two_point", "step": 1|2}` → `LevelStatus` (ждёт 3 с замера; 409 — качается; `step: 2` без `step: 1` → 409) |
| POST | `/api/level/calibration/forward` | `{"axis": "x+"…}` или `{"learn": true}` / `{"learn": false}` → `LevelStatus` |
| DELETE | `/api/level/calibration` | `LevelStatus` (сброс) |

`/api/level/calibration/level` без датчика → 503 «Level sensor is not connected».

**Телеметрия**: `Telemetry.level = {sensor_ok, calibrated, pitch_deg, roll_deg, wheels_cm}` (или `null`, если
сервиса нет); обновляется с каждой телеметрией.

## Экран

Виджет уровня — **вместо спидометра** (`speed.js`, тот же угол и тот же стиль металлической плашки, при
необходимости — выше/шире, но не перекрывая машину на карте и другие плашки), когда:
`settings.level.show_on_screen` и `level.sensor_ok`, и скорость по GPS < 1 км/ч не меньше 3 с подряд (или
скорости нет); пропадает сразу при скорости > 3 км/ч.

Содержимое (крупно и читаемо на ч/б ЭЛТ 720×480):
- продольный угол с силуэтом машины сбоку, наклонённым на этот угол (усиленно, чтобы 1–2° было видно), и
  поперечный — с силуэтом сзади; цифры со знаком, ориентир словами/стрелкой (какая сторона выше);
- «LEVEL» (галочка/рамка), когда оба угла ≤ 0,3°;
- сколько подложить под колёса (`wheels_cm`, ненулевые) — маленькая схема сверху с четырьмя колёсами;
- без калибровки — пометка `UNCAL`.
