# Контракт: датчик воздуха (Qingping Air Monitor Lite)

Датчик сам рассылает показания в вещании Bluetooth LE — подключаться не нужно, его приложение на телефоне работает
одновременно. Ядро только слушает (`fnav/core/advscan.py`) и хранит историю (`fnav/core/air.py`). На экране кинескопа
этих данных нет — только веб-интерфейс.

## Данные

| Поле | Единицы | Зоны (норма / повышено / зашкал) |
|---|---|---|
| `co2_ppm` | ppm | < 1000 / < 1500 / выше |
| `temp_c` | °C | 18–26 / 15–18 и 26–30 / вне |
| `humidity_pct` | % | 30–60 / 20–30 и 60–70 / вне |
| `pm25` | мкг/м³ | < 15 / < 35 / выше |
| `pm10` | мкг/м³ | < 45 / < 100 / выше |
| `battery_pct` | % | (в пакетах встречается редко) |

Зоны — в `web/admin/js/air-fmt.js` (`METRICS`), только для цвета.

Формат пакета (service data `0000fdcd-…`): `[служебный][тип устройства 0x24][MAC задом наперёд]`, дальше записи
«тип, длина, значение», little-endian: `01/4` — температура ÷10 (s16) и влажность ÷10 (u16); `12/4` — PM2.5 и PM10;
`13/2` — CO₂; `02/1` — батарея.

## Приём вещания (`fnav/core/advscan.py`)

Общий приёмник для датчика воздуха и солнечного контроллера Victron (power.md «Третья станция»). Слушаем окнами по
15 с: раз в минуту, пока играет музыка — раз в 3 минуты, при заднем виде на экране — не слушаем (радио у чипа одно на
Wi-Fi, колонку и станции; поиск идёт «редким» окном 30 из 200 мс, `pi/bluetooth/main.conf`). Окно берёт общий замок
подключений станций. Замер на Pi (2026-11-15): Victron — пакет раз в ~2 с, Qingping — 2 пакета за 40 с, то есть новое
показание воздуха приходит раз в 1–2 минуты (с музыкой — раз в 3–6).

## История и API

- По одной записи в минуту (последнее показание минуты), 7 дней, в памяти и в `air_history.json` (пишется раз в
  10 минут и при остановке ядра).
- `telemetry.air` — `{temp_c, humidity_pct, co2_ppm, pm25, pm10, battery_pct, age_s}`; нет показаний 15 минут — все
  значения `null`; датчик выключен или без адреса — `air: null` (плитки нет).
- `GET /api/air/history?hours=H` (1…168) — корзины `{t0, step_s, n, <поле>: {min[], avg[], max[]}}`: до суток — по
  минуте, 7 дней — по 15 минут (672 корзины); пустая корзина — `null`.
- Настройки `settings.air`: `enabled` (да), `mac` (`EC:4D:3E:7D:AE:4D`).

## Веб-интерфейс

- **Dashboard, плитка Air:** пять значений, цвет по зоне, под каждым — линия за последний час
  (`web/admin/js/air-chart.js` `sparkline`); обновляется раз в минуту.
- **Страница Air** (`pages/air.js`): по графику на значение за 7 дней — линия среднего, за ней бледная полоса
  мин…макс каждой корзины; цвет линии — вертикальный градиент по зонам (зелёный / янтарный / красный), пунктиром —
  границы зон, внизу — дни недели; под графиком мин / среднее / макс за 7 дней. Пропуски в данных — разрывы линии.
