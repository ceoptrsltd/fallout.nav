## Видеовыход на RV-50 — композитный напрямую с CM4 (2026-10-21)
- Сигнал: вывод **111 `VDAC_COMP`** разъёма J2 модуля CM4 (впаян провод на ножку штекера модуля), земля — GND платы.
  Как найти ножку без подсчёта: в нечётном (внутреннем) ряду J2 земли идут через две сигнальные —
  `101 103 105 [107 GND] 109 111 [113 GND] …`; нужная — **левая из двух между первыми двумя «землями»** от края с выводом 101
  (сосед сразу слева — земля 113). Ошибка на одну ножку = 109 `PCIe_nRST` (держится на 0 В).
- Монитор: вход канала 2, видео на контакт ≈ 82 Ом к массе, земля на контакт 0 Ом. Конвертер HDMI→AV не нужен.
- Настройки: `dtoverlay=vc4-kms-v3d,cma-256,composite`, `enable_tvout=1`, `core_freq_min=500`,
  cmdline `video=Composite-1:720x480@60ie,tv_mode=NTSC,margin_left=62,margin_right=86,margin_top=26,margin_bottom=26`.
  - **NTSC 480i/60 Гц**: на 60 Гц RV-50 держит кадровую синхронизацию стабильно; PAL 576i/50 (а также 288p, Mono,
    вывод через прошивку/fkms, затемнение, сдвиг DC-уровня) — кадр прыгал по вертикали.
  - **Поля (margins)**: на 60 Гц монитор показывает только центральные ~80 % по ширине и ~90 % по высоте; картинка
    ужата в видимую зону и сдвинута на 12 px (монитор зеркалит — «вправо на экране» = влево в сигнале).
  - **Зеркало**: `settings.display.mirror_x = true` (RV-50 сам отражает картинку — он для камеры заднего хода).
  - Монитор плохо развязывает входы: родная камера на соседнем входе сбивает наш канал и наоборот.
- Служебные тест-картинки: `FNAV_DISPLAY_URL=http://127.0.0.1/display/test-pattern.html?mode=bw&clean=1`
  (или `mode=seq`, `mode=bars`) в `/etc/fnav/display.env`, затем `sudo systemctl restart fnav-display`; убрать строку — вернуть навигацию.
